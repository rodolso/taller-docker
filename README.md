# Advertising Sales Predictor API

A Dockerized REST API that predicts product sales based on advertising spend across TV, radio, and newspaper channels. Built with Flask + scikit-learn, ready to deploy on Render.com.

---

## How it works

The model is a **Linear Regression** pipeline trained on the classic [Advertising dataset](https://www.kaggle.com/datasets/ashydv/advertising-dataset). It takes ad spend as input and predicts expected sales.

The model is trained automatically at **Docker build time** — no need to run anything manually.

---

## Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/` | Health check |
| `GET` | `/api/v1/predict` | Predict sales from ad spend |
| `GET` | `/api/v1/retrain` | Retrain model on new data |

### Predict

```
GET /api/v1/predict?tv=100&radio=20&newspaper=10
```

**Parameters** (all optional — missing values are mean-imputed by the pipeline):

| Param | Type | Description |
|-------|------|-------------|
| `tv` | float | TV advertising budget |
| `radio` | float | Radio advertising budget |
| `newspaper` | float | Newspaper advertising budget |

**Response:**
```json
{
  "predictions": 14.32
}
```

## Run locally with Docker

```bash
# Build
docker build -t advertising-api .

# Run
docker run -p 5000:5000 advertising-api
```

Then open: [http://localhost:5000](http://localhost:5000)

---

## Run locally without Docker

```bash
pip install -r requirements.txt
python model.py       # train and serialize the model
python app.py         # start the API
```

---

## Deploy to Render

1. Push this repo to GitHub
2. Create a new **Web Service** on [Render](https://render.com)
3. Select **Docker** as the environment
4. Render will build the image and inject the `PORT` variable automatically

## Project structure

```
├── app.py              # Flask API
├── model.py            # Training script (runs at build time)
├── ad_model.pkl        # Serialized model (generated by model.py)
├── requirements.txt
├── Dockerfile
└── data/
    ├── Advertising.csv         # Training data
    └── Advertising_new.csv     # Data for the retrain endpoint
```
